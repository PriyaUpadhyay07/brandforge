Build a complete, polished web application called "BrandForge" — a design system generator that lets users create, preview, save, and export a fully custom brand design system in minutes.

=== CORE CONCEPT ===
BrandForge takes a few simple inputs from the user (brand name, industry, one primary color, and a "personality" preference) and automatically generates a complete, professional design system: a full color palette (10 shades from lightest to darkest, computed algorithmically — not hardcoded), a matching font pairing (heading + body font), a spacing/sizing scale, and a live gallery of real UI components (buttons, cards, badges, inputs, navbar, alerts, footer) all styled using the generated tokens. Think of it as "generate your own mini design system like Stripe or Linear has, but for your brand, in 30 seconds."

=== TECH STACK (keep this simple and low-risk) ===
- Frontend: React + Vite + TailwindCSS + Framer Motion for smooth transitions
- Color math: use a lightweight JS color library (e.g. "chroma-js" or "colord") to programmatically generate tints/shades from the single primary color the user picks — DO NOT hardcode palettes, compute them mathematically (this must work offline with zero API calls and zero errors)
- Backend: Node.js + Express, minimal routes only
- Database: SQLite (via better-sqlite3) with ONE simple table called `brand_kits`:
  columns: id, brand_name, industry, primary_color, personality (string), heading_font, body_font, tagline (nullable), tone_notes (nullable), created_at
  Purpose of this table: lets users save multiple generated brand kits and revisit/edit them later — this is the "Connected" real-integration requirement, a genuine persistent backend, not fake local state.
- AI Integration (KEEP THIS SMALL AND ISOLATED): use the Anthropic API for exactly ONE feature — generating a short brand tagline + 3-bullet tone-of-voice guide. This is a single non-streaming request/response call (NOT a chat interface), triggered by one button click. Input to the AI: brand name, industry, personality sliders. Output: JSON with { tagline: string, toneGuidelines: [3 short strings], brandDescription: 1-2 sentences }. If the AI call fails for any reason, the app must gracefully show a "Regenerate" button and default placeholder text — never crash or block the rest of the app. This isolation keeps token usage low and avoids chat-related bugs.

=== DESIGN SYSTEM RULES (this IS the product, so it must be beautiful) ===
- The app's OWN chrome (landing page, wizard, nav) should look like a premium SaaS design tool — dark charcoal background option, generous whitespace, soft shadows, rounded-xl corners, smooth micro-animations on hover/click.
- Typography: use 2 well-paired Google Fonts for the app's own UI (e.g. a clean sans for body + a distinct display font for headings).
- Include a light/dark mode toggle for the app itself.
- All generated color palettes must be displayed as swatch strips with hex codes visible and a "copy hex" button on hover.

=== PAGES / SCREENS (all required — this is the multi-screen requirement) ===
1. **Landing Page** — Hero explaining BrandForge ("Generate a complete design system for your brand in 30 seconds"), 3-step visual explainer (Input → Generate → Export), a few example brand kit previews as visual cards, CTA "Start Building".
2. **Brand Wizard Page** — A clean 3-step form: Step 1: brand name + industry (dropdown: Tech, Food & Beverage, Fashion, Health, Finance, Creative); Step 2: primary color picker (with live preview swatch); Step 3: personality sliders (Minimal ↔ Bold, Playful ↔ Serious, Modern ↔ Classic). Show a live preview panel on the side that updates in real time as the user adjusts inputs.
3. **Generated Design System Page** (the core output page) — organized into clear sections:
   a. Color Palette section: full 10-shade ramp generated from the primary color, plus auto-generated complementary/neutral colors, each with hex code and copy button
   b. Typography section: the recommended font pairing rendered as actual live headings/body text samples at different sizes (H1–H6, body, caption)
   c. Spacing & Radius scale: visual blocks showing the spacing system (4px–64px) and border-radius options
   d. Component Gallery: real, working components styled with the generated tokens — primary/secondary/ghost buttons, a card component, input fields, badges/tags, an alert banner, a mini navbar, and a footer — all in a responsive grid so the user can see their design system "in action"
   e. Brand Voice card: the AI-generated tagline + tone guidelines (with a "Regenerate with AI" button)
4. **My Saved Kits Page** — Grid of all brand kits the user has saved (pulled from the SQLite database), each shown as a small card with its color swatch + name, with Open / Duplicate / Delete actions.
5. **Export Page** — For the currently generated kit, offer three copyable/downloadable export formats: (1) CSS custom properties (:root variables), (2) Tailwind config snippet (theme.extend.colors etc.), (3) plain JSON design tokens file. Each with a "Copy to clipboard" button and a "Download file" button.
